# スパイ7分の1 - セットアップ手順(Phase 2・GitHub Pages版)

## 実装済みの範囲
- ホーム画面(ルーム作成 / 参加)
- ロビー(参加者のリアルタイム同期、3〜7人でホストが開始可能)
- 役職の秘密決定(スパイ75% / 平和村25%)と、本人だけへの役職公開
- **GAME1・GAME3: 漢字伝達ゲーム**
  - 回答者以外の全員がお題を見て、順番に漢字1字ずつヒントを出す(制限時間15秒/人)
  - 回答者はヒントだけを見て、4択からお題を当てる(制限時間15秒)
- **GAME2・GAME4: 判断・一致ゲーム**
  - 全員に同じ質問を表示し、4択から回答(制限時間20秒)
  - 最多得票の選択肢と一致した人数が「総人数 − 1人」以上なら成功(要調整可)
- 各ゲームの結果表示(成功/失敗、正解、回答内訳)
- 作戦会議(60秒、アプリ内チャットなし)
- 投票(「スパイはいない」選択肢あり、自分には投票不可)
- 投票結果 → 役職公開演出 → 勝敗判定 → 「もう一度遊ぶ」

## 設計上の簡略化(仕様書からの変更点)
- 伝達ゲームは「イラスト」ではなく「漢字伝達」として実装(絵を描く同期の実装コストを避けるため)
- 各ミニゲームは1ラウンドのみ(仕様書にある複数ラウンド・時間内周回は今回のMVPには未実装)
- 役職決定・ゲーム進行の一部判定はホスト端末が計算する方式(友人内の信頼が前提。サーバー権威ではありません)

## セットアップ手順

### 1. Firebaseコンソールでの設定
1. 既存のFirebaseプロジェクトを開く
2. 「構築」→「Authentication」→「Sign-in method」で **匿名（Anonymous）** を有効化
3. 「構築」→「Firestore Database」でデータベースを作成(まだなければ)
4. `firestore.rules` の内容をFirestoreの「ルール」タブに貼り付けて公開
5. 「プロジェクトの設定」→「マイアプリ」で `firebase-config.js` に設定値を反映(前回設定済みならそのままでOK)
6. 「Authentication」→「Settings」→「承認済みドメイン」に `<GitHubユーザー名>.github.io` が追加済みか確認

### 2. GitHubへの反映
```bash
cd spy-game
git add -A
git commit -m "Phase2: GAME1-4, discussion, voting, result"
git push
```
GitHub Pagesはpushすれば自動的に反映されます(数分かかる場合があります)。

### 3. テスト方法
- 3〜7人分のブラウザ/端末で同じルームIDに参加
- ロビーでホストが開始 → 各自の役職を確認(他人の役職が見えないこと)
- GAME1(漢字伝達): 回答者以外が順番にヒントを出し、回答者が4択で当てる
- GAME2(判断・一致): 全員同時に回答、結果を確認
- GAME3・4も同様に進行
- 作戦会議(60秒)→ 投票 → 結果発表(投票結果→役職公開→勝敗)まで一通り確認
- 「もう一度遊ぶ」で正しくロビーに戻り、前回のデータが残っていないか確認

## 既知の制限事項
- タイマーは各端末のローカル時計基準のため、端末間で時計がずれていると表示に多少の誤差が出ます
- ホストが操作中にページを閉じるとゲーム進行が止まります(サーバー権威ではないため)
